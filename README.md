# คัมภีร์ฮีบรู — ฉบับถอดความภาษาไทย

การถอดความคัมภีร์ฮีบรู (ทานัค) ทีละข้อ — ซื่อตรงต่อตัวอักษรต้นฉบับ

## ฮีบรูมาก่อน

ฉบับถอดความนี้มีอยู่เพื่อนำท่านไปสู่ภาษาฮีบรู — ไม่ใช่เพื่อแทนที่
สิ่งที่อ่านอยู่เสมอคือฮีบรู — พยัญชนะ สระ และเครื่องหมายของมัน
ภาษาไทยด้านล่างเป็นหน้าต่าง ไม่ใช่สิ่งทดแทน
ที่ใดทั้งสองต่างกัน ฮีบรูคือความถูกต้อง

## พระนาม

ทุกที่ที่พระนามสี่อักษรปรากฏ เราเขียนว่า **ยาห์เวห์** —
ไม่แทนด้วยตำแหน่ง ไม่เปลี่ยนเป็นคำสามัญ
เราไม่เขียน **พระเยโฮวาห์** (รูปผสม) ไม่เขียน
**องค์พระผู้เป็นเจ้า** (ตำแหน่ง — ไม่ใช่นาม)
และไม่วาง **พระเจ้า** บนที่นั่งของพระนาม
พระนามยืนอยู่ตามที่เป็น ในทุกแห่ง —
เพื่อให้เห็นเสมอว่าพระนามอยู่ที่ใด

## อาเลฟ-ทาว — ⟨את⟩

ในประโยคภาษาไทย ท่านจะเห็น **⟨את⟩** ถูกเก็บรักษาไว้
ในภาษาฮีบรู אֵת เป็นคำเล็ก ๆ ที่ชี้ไปยังกรรมของการกระทำ
ภาษาไทยไม่มีคำเทียบเท่า และฉบับแปลส่วนใหญ่ตัดมันทิ้งอย่างเงียบ ๆ
เราปล่อยให้มันปรากฏในวงเล็บ — เพราะมันเป็นส่วนหนึ่งของ
โครงสร้างภาษา แทนที่จะลบ เราเลือกที่จะแสดงการมีอยู่ของมัน

## คำใน ⟨วงเล็บ⟩

วงเล็บ ⟨แบบนี้⟩ ทำเครื่องหมายคำที่ **ไม่มีในภาษาฮีบรู** —
คำเสริมที่จำเป็นเพื่อให้ประโยคไทยยืนได้
แทนที่จะผสมอย่างไร้ร่องรอย เราวางไว้ในวงเล็บ —
เพื่อให้คำฮีบรูต้นฉบับกับคำที่เสริมเพราะความจำเป็นของภาษาไทย
แยกแยะได้เสมอ

## ชื่อและตำแหน่ง

คำฮีบรูที่ชี้ถึงองค์บริสุทธิ์ — **เอโลฮิม**, **เอล**, **ชัดดาย**,
**อาโดนาย**, **ยาห์** — เขียนตามเสียงของมัน
ไม่ถูกบีบให้เป็นคำเดียวกันทั้งหมด แต่ละคำมีน้ำหนักของตัวเอง
ชื่อคนและสถานที่ก็ตามรูปฮีบรู: อัฟราฮัม, ยิทสฮัก, ยาอาโคฟ,
โมเช, เยรูชาลายิม

## คำที่ทำเครื่องหมายไว้

- **เคเซด** (חֶסֶד) — ความรักซื่อสัตย์แห่งพันธสัญญา
  ไม่ใช่แค่ "ความเมตตา" ไม่ใช่แค่ "ความรัก"
  ไม่มีคำไทยคำเดียวที่แบกมันได้
- **เชโอล** (שְׁאוֹל) — ที่อยู่ของผู้ตายตามที่ฮีบรูกล่าว
  ไม่ใช่ "นรก"
- **เนเฟช**, **รูอัค**, **คาโวด** — ตามบริบท (จิตวิญญาณหรือชีวิต,
  วิญญาณหรือลม, พระสิริหรือน้ำหนัก) — ไม่ถูกตรึงในคำเดียว

## แต่ละข้อในแสงของตัวเอง

แต่ละข้อถูกถอดความตามที่มันกล่าว ณ ที่ของมัน —
อ่านในความเชื่อฮีบรูที่มีเอโลฮิมหนึ่งเดียว
ไม่เติมคำสอนที่มาภายหลัง ไม่อ่านตอนจบของเรื่องเข้าไปในตอนต้น
ให้ถ้อยคำถือความหมายที่มันแบก ณ ที่ของมัน — นั่นคือเจตนา

## โครงสร้างไฟล์

หนึ่งข้อหนึ่งไฟล์: ตัวข้อเอง พร้อมความหมายทีละคำวางเคียงฮีบรู —
เพื่ออ่านคำฮีบรูแต่ละคำต่อหน้าคำไทยของมัน
